为什么是 Auto Router

目录结构，就是你的 API 设计。

零配置自动路由、嵌套目录、动态参数与内置权限元数据——把文件系统直接映射成 HTTP 路由。

→

文件命名即路由

get-users.ts → GET /api/users，get-[id].ts → GET /api/:id。无需手动注册。

// 控制器目录
controllers/
  get-users.ts        → GET /api/users
  post-login.ts       → POST /api/login
  users/[userId]/get.ts → GET /api/users/:userId
?

权限元数据内建

createHandler 携带 requiresAuth 元数据，forcePublic / forceProtected 批量覆盖。

// 权限声明
createHandler(handler, { requiresAuth: true })
autoRouter({ defaultRequiresAuth: false })
!

多前缀 · 多配置 · ignore

同一控制器注册到多个前缀（版本化/本地化），合并多目录配置，按正则忽略文件或文件夹。

autoRouter({
  dir: './controllers',
  prefix: ['/api', '/v2'],
  ignore: ['^__'],
})

命名规则

一段文件名，三种写法。

基本格式、单参数、多参数与动态目录——所有规则都可预测、可校验。

文件注册为说明
get.tsGET /api以目录路径为路由
get-users.tsGET /api/users文件名附加路径
get-[id].tsGET /api/:id单参数
get-[userId]-posts.tsGET /api/:userId/posts多参数，- 变 /
users/[userId]/get.tsGET /api/users/:userId动态目录（深层推荐）
users/get-[id].tsGET /api/users/:id目录参数 + 文件参数组合

用法

三种导出方式，一套心智模型。

纯函数、createHandler 包装器、以及带路由级中间件的进阶写法。

import { autoRouter } from '@chaeco/auto-router';

const app = new YourFramework();

app.extend(autoRouter({
  dir: './controllers',
  prefix: '/api',
}));

app.listen(3000);

// controllers/get-users.ts
export default async (ctx) => {
  ctx.res.body = { users: [] };
};
import { createHandler } from '@chaeco/auto-router';

// 受保护路由
export default createHandler(
  async (ctx) => {
    ctx.res.body = { userId: ctx.currentUser?.id };
  },
  { requiresAuth: true, description: 'Get current user info' },
);

// 覆盖全局 defaultRequiresAuth: true
export default createHandler(
  async (ctx) => { ctx.res.body = { success: true }; },
  { requiresAuth: false },
);
import { z, zodValidator } from '@hoajs/zod';
import { createHandler } from '@chaeco/auto-router';

const LoginSchema = z.object({
  username: z.string().min(1),
  password: z.string().min(1),
});

export default createHandler(
  async (ctx) => {
    // ctx.req.body 已被 zodValidator 校验并解析
    ctx.res.body = { success: true };
  },
  { description: 'User login' },
  [zodValidator({ body: LoginSchema })],  // 路由级中间件
);

Cloudflare Workers

边缘运行时，原生支持。

构建期清单 CLI + 零依赖 createWorkerRouter，适配 fetch(request, env, ctx) 签名。

⚙

构建期清单

CLI 扫描控制器目录，生成静态 TS 清单。

npx auto-router-build-manifest ./controllers \
  ./worker-routes.ts --prefix /api
λ

createWorkerRouter

零依赖路由，fetch(req, env, ctx) 签名，O(n) 匹配。

const router = createWorkerRouter<Env>({ routes });
export default { fetch: router.fetch };
!

为什么不用 staticAutoRouter

Workers 用 Web Platform fetch 签名，没有中间件栈。createWorkerRouter 与之完全匹配。

// 返回对象 → 自动 JSON
return { users: ['Alice'] };
