Quick Start 快速开始

Get started in minutes. Just two steps. 几分钟即可开始。只需两步。

1

Create your controllers 创建控制器

File names define HTTP routes. Use [param] for dynamic segments. 文件名定义 HTTP 路由。使用 [param] 表示动态参数。

📁controllers/
get-users.ts → GET /api/users
get-[id].ts → GET /api/:id
post-login.ts → POST /api/login
2

Mount the router 挂载路由器

Just one line to register all routes automatically. 只需一行代码即可自动注册所有路由。

app.ts 
import { autoRouter } from '@chaeco/auto-router'

const app = createApp()

app.extend(
  autoRouter({
    dir: './controllers',
    prefix: '/api',
  })
)

app.listen(3000)

File Naming Convention 文件命名规则

Every route file name encodes the HTTP method and URL structure. 每个路由文件名编码了 HTTP 方法和 URL 结构。

Basic Formats 基本格式

File name 文件名 Registers 注册为
get-users.ts GET /api/users
post-login.ts POST /api/login
get-[id].ts GET /api/:id
admin/get-users.ts GET /api/admin/users

Dynamic Parameters 动态参数

Wrap parameter names in [brackets]. Each - between segments becomes / in the URL. 用 [方括号] 包裹参数名。段之间的 - 会变成 URL 中的 /。

Single Parameter 单参数

get-[id].ts → GET /api/:id
delete-[id].ts → DELETE /api/:id

Multiple Parameters 多参数

get-[userId]-posts.ts → GET /api/:userId/posts
get-[userId]-[postId].ts → GET /api/:userId/:postId

Dynamic Directory Names 动态目录名

Directory names can also contain [param] brackets. 目录名也可以包含 [param] 方括号。

File path 文件路径 Registers 注册为
users/[userId]/get.ts GET /api/users/:userId
users/[userId]/posts/get.ts GET /api/users/:userId/posts
users/[userId]/posts/[id]/get.ts GET /api/users/:userId/posts/:id

Export Methods 导出方式

Three ways to export route handlers. 三种导出路由处理器的方式。

Method 1: Pure Function 方式 1：纯函数

Simplest form. Route inherits global defaultRequiresAuth. 最简单的形式。路由继承全局 defaultRequiresAuth。 

// controllers/get-users.ts
export default async (ctx) => {
  ctx.res.body = { users: [] }
}

Method 2: createHandler 方式 2：createHandler

Use when you need per-route metadata (auth, description, tags). 当需要单个路由的元数据（权限、描述、标签）时使用。 

import { createHandler } from '@chaeco/auto-router'

export default createHandler(
  async (ctx) => {
    ctx.res.body = { success: true }
  },
  {
    requiresAuth: true,
    description: 'Get user profile',
    tags: ['Users'],
  }
)

Method 3: Route-level Middlewares 方式 3：路由级中间件

Third argument of createHandler — Koa/Hoa-style middlewares that run before the handler. Attach validation middleware like @hoajs/zod. createHandler 的第三参数 —— Koa/Hoa 风格中间件，在 handler 之前执行。可挂载 @hoajs/zod 等校验中间件。 

import { z, zodValidator } from '@hoajs/zod'
import { createHandler } from '@chaeco/auto-router'

const LoginSchema = z.object({
  username: z.string().min(1),
  password: z.string().min(1),
})

export default createHandler(
  async (ctx) => {
    ctx.res.body = { success: true }
  },
  { description: 'User login' },
  [zodValidator({ body: LoginSchema })]
)

Auth & Permissions 权限与认证

Built-in auth metadata with fine-grained control over route access. 内置权限元数据，精细控制路由访问。

Blacklist Mode 黑名单模式

Public by default. Mark only protected routes. 默认公开。只标记受保护的路由。 

autoRouter({
  dir: './controllers',
  defaultRequiresAuth: false,
})

Whitelist Mode 白名单模式

Protected by default. Mark only public routes. 默认受保护。只标记公开的路由。 

autoRouter({
  dir: './controllers',
  defaultRequiresAuth: true,
})

Bulk Auth Overrides 批量权限覆盖

Use forcePublic and forceProtected to declare routes that are always public or always protected. 使用 forcePublic 和 forceProtected 声明始终公开或始终受保护的路由。 

autoRouter({
  dir: './controllers',
  defaultRequiresAuth: true,
  forcePublic: [
    '/api/auth/*',        // all auth routes are public
    '/api/public/*',      // public data routes
  ],
  forceProtected: [
    '/api/admin/*',       // all admin routes protected
    'POST /api/users',    // only POST /api/users
  ],
})

API Reference API 参考

Clean, minimal API. Three main exports. 简洁的 API。三个主要导出。

autoRouter(options) Core

Factory function. Returns an async plugin for app.extend(). 工厂函数。返回一个用于 app.extend() 的异步插件。

createWorkerRouter(options) Workers

For Cloudflare Workers. Zero-dependency router with fetch(req, env, ctx) signature. 用于 Cloudflare Workers。零依赖路由器，支持 fetch(req, env, ctx) 签名。 

import { createWorkerRouter } from '@chaeco/auto-router/worker-manifest'
import { routes } from './worker-routes'

const router = createWorkerRouter({ routes })

export default { fetch: router.fetch }
createHandler(handler, meta?, middlewares?) Export

Wraps a handler with metadata and optional Koa/Hoa-style middlewares that run before the handler. 为 handler 附加元数据和可选的路由级中间件，中间件在 handler 之前执行。
